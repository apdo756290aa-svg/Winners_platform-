الفصل الثالث - الدرس 1: البنية العامة لتطبيقات الويب

1. ما هو تطبيق الويب؟

برنامج يعمل عبر الإنترنت وعادة يُستخدم من خلال متصفح الويب (مثل Chrome)، أو قد يُثبت أحياناً على الجهاز (مثل خدمات التسوق، الفيديو، والبريد الإلكتروني).

2. هيكلية تطبيق الويب ثلاثية الطبقات (3-Tier Architecture)

• الواجهة الأمامية (Frontend): الجزء الذي يراه المستخدم ويتفاعل معه مباشرة في المتصفح (عرض المحتوى واستقبال المدخلات).
• الواجهة الخلفية (Backend): الجزء الذي يعمل على الخادم لمعالجة الطلبات وتطبيق قواعد التطبيق.
• قاعدة البيانات (Database): مسؤولة عن تخزين وحفظ وتوفير البيانات عند الحاجة (معلومات المنتجات، المستخدمين، سجل الطلبات).

3. تدفق الطلب في النموذج المبسط

المستخدم ⬅️ الواجهة الأمامية (تستقبل وتدير الإدخال) ⬅️ الواجهة الخلفية (تعالج وتطلب) ⬅️ طبقة البيانات (تبحث وتسترجع) ⬅️ تعود النتائج للشاشة.

الفصل الثالث - الدرس 2: طرق اتصال تطبيقات الويب

1. نموذج العميل والخادم (Client-Server)

• العميل (Client): جهازك ومتصفحك الذي يرسل الطلبات (Request).
• الخادم (Server): النظام على الإنترنت الذي يستقبل الطلب ويعالج ويرسل الاستجابة (Response).

2. بروتوكولات الأمان وتركيبات الطلب

• HTTP / HTTPS: البروتوكول الأساسي، وHTTPS يضيف تشفير ومصادقة عبر بروتوكول TLS (السرية، السلامة، مصادقة الخادم).
• طرق الطلب: GET لاسترجاع البيانات، POST لإرسال البيانات لمعالجتها (مثل تسجيل الدخول).
• رموز الحالة: 200 (نجاح)، 404 (المورد غير موجود)، 500 (خطأ داخلي بالخادم).

3. واجهة برمجة التطبيقات (API) وصيغة JSON

• API: وسيط أو باب منظم يسمح لبرنامج بطلب بيانات أو وظائف من برنامج آخر.
• JSON: صيغة نصية شائعة لتبادل البيانات المهيكلة باستخدام كائنات ومصفوفات وقيم.

الفصل الثالث - الدرس 3: أساسيات تقنية الواجهة الأمامية

1. تقنيات الويب الثلاث الأساسية

• HTML: لتحديد البنية والهيكل (العناوين، الفقرات، الصور).
• CSS: لتنسيق المظهر والديكور (الألوان، الخطوط، التخطيط).
• JavaScript: لإضافة السلوك والتفاعل والأزرار المستجيبة.

2. الواجهة الأمامية الحديثة

• HTML الدلالية (Semantic HTML): استخدام عناصر مثل <header> و <nav> و <main> لتوضيح الوظيفة، مما يساعد قارئ الشاشة لذوي الإعاقة ومحركات البحث (SEO).
• التصميم المتجاوب (Responsive Design): تكيف التخطيط تلقائياً مع أحجام الشاشات المختلفة (نهج الأولوية للجوال).
• أطر العمل (Frameworks): مكتبات جاهزة مثل React و Vue و Next.js لتسويق التطوير بكفاءة.

الفصل الثالث - الدرس 4: أنواع الوسائط وخصائصها

1. مقارنة الوسائط الإعلامية

• التلفزيون: جمهور كبير، اتصال باتجاه واحد.
• الراديو: صوتي، يُستمع إليه أثناء التنقل.
• الصحف: مطبوعة ومتاحة دون اتصال.
• الموقع الإلكتروني: يجمع النصوص والصور والفيديو والصوت، قابل للتحديث، ويدعم التفاعل ثنائي الاتجاه.
• وسائل التواصل الاجتماعي: نشر سريع وتشجيع المشاركة والتناقل الشفهي.

الفصل الثالث - الدرس 5: تصميم المعلومات وتجربة المستخدم

1. أدوات تصميم تجربة المستخدم (UCD)

• شخصية المستخدم (Persona): تمثيل لنمط المستخدم يستند للبيانات (الأهداف، الاحتياجات، السياق).
• المخطط الهيكلي (Wireframe): رسم أولي لتحديد أماكن العناصر وأولوياتها قبل الألوان والزخارف.
• مبادئ CRAP البصرية: التباين (Contrast)، التكرار (Repetition)، المحاذاة (Alignment)، التقارب (Proximity).
• قابلية الاستخدام وإمكانية الوصول (Accessibility): تمكين الجميع من استخدام الموقع.

الفصل الثالث - الدرس 6: تقييم والتحسين التكراري للمواقع

1. طرق التقييم (نوعي وكمي)

• التقييم النوعي (لماذا): اختبارات قابلية الاستخدام، المقابلات، والتقييم الإرشادي للخبراء (الاتساق، منع الأخطاء، وضوح حالة النظام).
• التقييم الكمي (كم): تحليلات الويب ومؤشرات مثل PV (مشاهدات الصفحة)، معدل الارتداد (Bounce Rate)، ومعدل التحويل (CVR).

2. دورة التحسين التكراري (PDCA والتفكير التصميمي)

• دورة PDCA: خطط (Plan) ⬅️ نفذ (Do) ⬅️ تحقق (Check) ⬅️ تصرف (Act).
• التفكير التصميمي: التعاطف ⬅️ التعريف ⬅️ توليد الأفكار ⬅️ النموذج الأولي ⬅️ الاختبار.
• اختبار A/B: مقارنة نسختين بعرض فرق واحد واضح ومحدد لمعرفة أيهما أفضل.
